# SICO 2.0 — Boa Castanha MOZ LDA

Sistema de gestão de stock, vendas, vendedores, despesas e relatórios.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `sico-2-0`.
2. Envie `index.html` e este `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Guarde e aguarde o GitHub Pages publicar o sistema.

O endereço será semelhante a:
`https://SEU-USUARIO.github.io/sico-2-0/`

## Dados e autenticação

O sistema mantém funcionamento local e possui integração com Firebase/Firestore quando configurada e disponível. Antes de colocar o sistema em produção, configure as regras do Firebase e reveja as permissões do projeto.

## Estrutura

- `index.html` — aplicação SICO completa, pronta para GitHub Pages.
- `README.md` — instruções do projeto.
- `.gitignore` — evita ficheiros locais/temporários de desenvolvimento.

## Importante

Não coloque neste repositório dados reais de clientes, vendedores, documentos de identificação, backups JSON ou outros ficheiros privados.
